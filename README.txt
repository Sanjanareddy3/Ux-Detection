# UX Detective – HCI Project

A multi-page Human-Computer Interaction learning website built using HTML, CSS and vanilla JavaScript.

## Run the website
1. Extract `UX-Detective.zip`.
2. Open the extracted `UX-Detective` folder.
3. Double-click `index.html` to open it in Chrome/Edge.
4. Recommended: open the folder in VS Code and use the Live Server extension.

No installation, backend, or API key is required. Google Fonts are optional; the site has system font fallbacks.

## Pages
- Dashboard – overview and quick navigation
- Case Files – fictional interface investigation scenarios; save findings
- Heuristic Lab – evaluate a sample interface using 10 usability heuristics and severity ratings
- Challenges – scenario-based HCI quiz with instant feedback
- Accessibility Lab – text size, contrast, keyboard support demonstration and checklist
- Reports – local progress summary and text export

## HCI syllabus connections
- Unit I: cognition, memory, feedback, individual differences and input/output interaction
- Unit II: interaction styles, navigation, WIMP-inspired interface elements, ergonomics and engagement
- Unit III: user-centred design, screen layout, prototyping, usability and heuristics
- Unit IV: evaluation, universal design, accessibility and error handling
- Unit V: dialog and feedback patterns; collaborative case sharing is a possible future extension

## Notes
This is an educational prototype. Sample cases are fictional scenarios, not audits of real websites. Progress is stored in browser LocalStorage and remains on that browser/device. The accessibility controls are demonstrations and do not constitute WCAG certification.
